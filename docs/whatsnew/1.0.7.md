# What's New — v1.0.7

## ✨ 新功能

- **评论「已读」**：不打算回复的评论（比如 4★ 好评）点一下「已读」，即从 Play Console 页和 Batch Reply 页同时消失；可撤销上一条，也能切到「只看已读」逐条标回未读
- **评论本地累积保留**（最多 180 天）：Google 每次只返回最近 7 天，现在本地不再覆盖旧数据——长假挂机每天定时拉取，回来能看到整段时间的评论，且照常可在 app 内回复
- **需求文档支持单文件 HTML**：Generate 页、补充测试点、风险沉淀三处都能直接导入 HTML PRD
- **Bug 页支持按 ID 批量选择**，并导出带详情的 xlsx
- **Batch Reply 草稿本地持久化**：已生成未提交的回复不会因进程重启丢失，不用重新调 API 生成
